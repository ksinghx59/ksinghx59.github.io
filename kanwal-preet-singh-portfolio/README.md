# Kanwal Preet Singh — Portfolio

A static personal portfolio website for a Mechanical Engineering Master's student.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling
- `script.js` — mobile navigation

## Add your projects
For each project, replace a placeholder project card in `index.html` and add your CAD render/image to an `images/` folder.

Suggested project format:
1. Project title
2. One-line category (CAD / CAM / FEM / Manufacturing)
3. 2–4 sentence technical description
4. Key software/tools
5. GitHub or case-study link
6. 2–4 project images

## Publish with GitHub Pages
Create a repository named `ksinghx59.github.io`, upload these files to the repository root, then enable GitHub Pages from Settings → Pages. GitHub Pages can publish static HTML/CSS/JS directly from a repository.
